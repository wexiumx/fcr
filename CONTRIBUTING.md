# Contributing

Thanks for your interest in contributing! All kinds of contributions are welcome.

## Ways to contribute

- **Bug reports:** found a bug? Please open an issue.
- **Ideas and suggestions:** have an idea or a feature request? Don't hesitate to open an issue and describe it.
- **Code:** if you want to help with code, you are welcome to do so. Pull requests are appreciated.

If you are unsure whether something is worth reporting or implementing, open an issue and ask. Don't be shy.

## Rules

### No LLMs

**No LLM-generated content is allowed in this project.**

All pull request code (including tests), issue descriptions, comments, public reviews, etc. must be human-written.

This applies to everything you submit here: code, tests, documentation, issue text, and discussion comments. Contributions that appear to be LLM-generated may be closed without review.

If you really want to use LLMs, that's your choice, but then please don't contribute to this project at all.

## Before opening a pull request

1. Keep pull requests small and focused on one thing.
2. Make sure the project builds and any existing tests pass.
3. Write a clear description of what the change does and why.

## Opening an issue
A good issue includes:
- Logs or screenshots, if they help
- a good name, for example: `Bug/Idea: short explanation`
